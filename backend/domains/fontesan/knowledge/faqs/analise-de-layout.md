# Análise de layout do estabelecimento

Dúvida comum de quem está montando, reformando ou reorganizando a cozinha/área de produção.

## Por que o layout importa para a vigilância sanitária

O objetivo do layout é evitar contaminação cruzada: o fluxo de alimento deve andar sempre para a frente, de "sujo" para "limpo", sem cruzar etapas.

## Pontos que a Fontesan avalia num layout

- **Fluxo unidirecional**: recebimento -> armazenamento -> pré-preparo -> preparo/cocção -> distribuição, sem o alimento pronto voltar a cruzar com alimento cru.
- **Separação de áreas críticas**: área de carnes cruas separada de área de manipulação de alimento pronto para consumo (ainda mais relevante com a Portaria CVS-3/2026, que passa a exigir temperatura controlada nessa área).
- **Distância entre pia de higienização de mãos e bancada de preparo**, com pia exclusiva para mãos (não para lavar utensílios) em local acessível.
- **Área exclusiva quando a norma exige**, como preparo de sushi (exigência nova da CVS-3/2026).
- **Posição de lixeiras**: com tampa, acionamento sem contato manual, longe de área de preparo.
- **Espaço para higienização de equipamentos** (desmontagem de fatiador/moedor/liquidificador passa a ser diária a partir da CVS-3/2026) sem interromper o fluxo principal.

## Como a Fontesan conduz essa análise

1. Levanta a planta ou o espaço real do estabelecimento.
2. Mapeia o fluxo de alimento etapa por etapa.
3. Aponta cruzamentos de risco (ex. cru passando por cima de pronto, mão suja tocando alimento pronto).
4. Sugere reorganização física ou de rotina quando não é viável mudar a estrutura.

## Quando escalar

- Pedido de projeto de layout completo/planta baixa — isso é entregável pago, encaminhar para orçamento.
- Espaço muito pequeno onde a separação ideal não é fisicamente possível — precisa de avaliação presencial para solução alternativa.
